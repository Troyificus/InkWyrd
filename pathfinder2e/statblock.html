Custom Variables

Define a value once, then reference it anywhere below with [TOKEN]. Built-ins: [STR] [DEX] [CON] [INT] [WIS] [CHA] insert the ability modifier exactly as PF2E writes it (e.g. +4) — no separate "to hit" version, since a Strike's actual bonus depends on the creature's proficiency rank (trained/expert/master/legendary), which varies per weapon and per creature rather than following one fixed formula from level alone; type each Strike's bonus directly in the Bonus field instead. Also available: [AC], [HP], [LEVEL].
